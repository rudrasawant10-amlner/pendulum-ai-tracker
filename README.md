# Pendulum AI Tracker | Python + OpenCV | MIT Project 1 by Rudra

> AI system that tracks pendulum motion using computer vision and predicts physics.

## Demo
![pendulum](https://upload.wikimedia.org/wikipedia/commons/9/9d/Simple_pendulum.gif)

## How it works
- OpenCV detects bob
- Calculates angle, velocity
- Predicts next position using physics equation: θ(t) = θ0 * cos(√(g/L) * t)

## Tech Stack
- Python
- OpenCV
- NumPy

## How to Run
pip install opencv-python numpy
python main.py
